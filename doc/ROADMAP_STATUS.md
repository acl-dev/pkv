## S0 退出可靠性验收

正常 SIGTERM/SIGINT 路径已完成本轮验证：未修改版本的相同六组输入
全部 SIGABRT，修复版全部正常退出且没有新增对应转储。旧异步处理器
关闭调度器描述符的行为已用实际二进制反汇编和转储调用链核实。
ACL 回调退出也已完成本轮验证：旧版 WiredTiger C++11 的四组输入中，
一次空闲退出 SIGSEGV，两组复制模式退出虽返回零，但两个库都需要恢复。
修复后每个 POSIX 配置覆盖空闲/次数上限/supervisor 断开、过期服务开关、
复制接收线程持有引用，共十二组；磁盘重启比较五种分页类型，WT 另在
禁止恢复的条件下重新打开两个库。源码和测试遵守本轮行宽、函数长度要求。
启动取消也已通过最终验证：等待线程在配置和原生库初始化前运行，正常
关闭回调在初始化末尾发布。取消未完成的初始化直接退出，不能据此声称
原生库已正常关闭；后续重新打开允许恢复，并验证既有分页值和 MOVE 决策。
初版取消分支曾写 stderr，被满管道阻塞；最终取消和等待线程失败分支

## 已验收阶段 S1：MOVE 与事务复制

已核实现有页批次、版本协商、工作区及副本读保留入口，具体接入顺序见
[MOVE 意图接入方案](MOVE_INTENT_INTEGRATION.md)。版本 4 已实现不可变
页批次与迁移意图的有序传输，完整组收齐后才构建内存重放工作区。
页批次组保留版本 3 编码；旧版订阅者在发送前拒绝迁移组。
传输基线的八种构建配置、全目标构建与 572 项选定回归已全部通过；该范围
并非全套测试。另以真实 RocksDB、WiredTiger 副本验证混合迁移组拒绝时，
前面的页写入不会部分提交，原 Hash 的 70 KiB 字段值保持不变；内存对照则成功
应用按同样方式构造的完整组。
真实 TCP 夹具覆盖五种分页类型、分片传输、无 COMMIT 等待、失败重连及
版本 4 到 3 的重连回退；这些证据不代表磁盘迁移组或公开 MOVE 已完成。

源端预留接口也已通过八配置的全目标构建与 130 项相关回归。观察者去重、
准备失败与取消、队列限额、原生准备失败、发布期间停止、工作区预算上限，
以及独立/EXEC 内真实内存迁移均有覆盖。页批次组保留原有快速路径，首次
迁移成功发布时才切换为有序收集。该范围与上述 572 项传输基线分别记录，
没有重复未修改协调器的整套故障矩阵，也没有把库级夹具记作公开命令验收。

公开命令已接入，包含 DB 范围、同库错误、过期源/目标、ACL 键提取、
集群限制、WATCH 和阻塞读取唤醒。MOVE 直接取得排他许可，退出旧单库事务
优化，保留 EXEC 逐命令提交语义。原生存储默认自动绑定决策日志；禁用与
既有标记不兼容时拒绝启动。命令说明见 [MOVE](MOVE.md)。

当前验收覆盖五种分页类型、真实主端到内存副本、主动过期删除事件、
原生重启及实际在线 MOVE 被中断后的恢复。主动过期检查曾使用错误删除
操作码，已用真实帧和目标 DB 物理计数定位并修正。最终冻结快照共 688
个源码文件，八配置全目标构建与 316 项选定回归通过；此前失败、中断和
局部通过的轮次分别保留，不计入最终通过数。

S1 当前范围已验收，完整 Redis 目标仍未完成。S2 仍需磁盘混合组持久化决策、
初始同步、PSYNC 与断线追赶；单条 MOVE 的持久化决策不能替代整个 EXEC
复制组的恢复。自动路径对空格等分隔字符仍有限制，需后续路径接口改造。

## 所有阶段持续执行的约束

本轮长度检查覆盖新增和修改区域；既有超长函数和行仍需全树审计与收敛。

- 新增或修改的代码行不超过 80 字符，每个函数不超过 200 行。
- List/Hash/Set/ZSet 等使用有界页和专用结构，避免整集合的大值序列化。
- 优先利用原生内存容器与 oneTBB，性能结论以分配和端到端测量为据。
- 构建或测试读取源码期间保持源码冻结；失败和成功证据分别记录。
- 完整目标包括命令、协议、持久化、复制、集群和运行可靠性。
